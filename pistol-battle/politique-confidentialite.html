Pistol Battle

Politique de confidentialité

Dernière mise à jour : 7 octobre 2026

Pistol Battle est un jeu mobile et web développé par Code A-Z. En résumé : le jeu ne collecte aucune donnée personnelle, ne demande aucun compte et n'affiche aucune publicité.

1. Éditeur du jeu

Le jeu est édité par Agnissan Isaac Valen, exerçant à titre indépendant sous le nom Code A-Z, Abidjan, Côte d'Ivoire.

  • E-mail : valenbouge@gmail.com
  • Téléphone / WhatsApp : +225 05 46 79 72 58

2. Aucune collecte de données personnelles

Pistol Battle ne collecte, ne transmet et ne partage aucune donnée personnelle, ni avec Code A-Z ni avec des tiers. Le jeu ne contient ni publicité, ni outil de mesure d'audience, ni traceur.

3. Ce qui est enregistré sur votre appareil

Pour que vous retrouviez votre partie, le jeu enregistre uniquement sur votre appareil (téléphone, ou navigateur pour la version web) :

  • votre progression : niveau atteint, pièces, étoiles, armes achetées et améliorées, défis et missions du jour ;
  • vos réglages : son, musique, vibrations, compteur d'images ;
  • des statistiques de jeu (temps de jeu, niveaux réussis ou abandonnés), visibles par vous seul dans Paramètres > Statistiques.

Ces informations ne quittent jamais votre appareil. Elles sont effacées si vous désinstallez le jeu (Android) ou si vous effacez les données du site dans votre navigateur (version web).

4. Aucun compte, aucun achat

Le jeu ne demande ni création de compte, ni adresse e-mail, ni numéro de téléphone. Il ne propose aucun achat intégré : les pièces se gagnent uniquement en jouant.

5. Permission Android utilisée

  • Vibreur — pour faire vibrer le téléphone quand vous tirez, êtes touché ou détruisez un ennemi. Vous pouvez désactiver les vibrations dans Paramètres.

Le jeu n'a pas accès à Internet pour envoyer des informations, ni à vos contacts, photos, micro, caméra ou position.

6. Liens vers Code A-Z

L'écran « À propos » propose des boutons vers le site, le WhatsApp et l'e-mail de Code A-Z. Ils ouvrent l'application concernée seulement si vous les touchez ; rien n'est envoyé automatiquement. Le site agnissanisaac.com a sa propre politique de confidentialité.

7. Google Play

Si vous installez le jeu depuis Google Play, Google peut traiter certaines données liées à votre compte Google et au téléchargement, selon ses propres règles de confidentialité. Code A-Z n'y a pas accès.

8. Enfants

Le jeu est destiné aux personnes de 13 ans et plus. Comme il ne collecte aucune donnée, aucune donnée d'enfant n'est collectée.

9. Modifications

Si le jeu évolue (par exemple l'ajout d'une sauvegarde en ligne, de publicités ou d'achats), cette politique sera mise à jour avant ces changements, et la date ci-dessus modifiée. Voir aussi les conditions d'utilisation du jeu.

10. Contact

Pour toute question, écrivez à valenbouge@gmail.com. En Côte d'Ivoire, l'autorité de protection des données personnelles est l'ARTCI : autoritedeprotection.ci.
