Budget Flow

Politique de confidentialité

Dernière mise à jour : 5 septembre 2026

Budget Flow est une application de gestion budgétaire personnelle développée par Code A-Z. Nous accordons une importance particulière à la protection de votre vie privée.

Aucune collecte de données

Budget Flow fonctionne entièrement hors-ligne. L'application ne collecte, ne transmet, ni ne partage aucune donnée personnelle avec Code A-Z ou avec des tiers. Toutes les informations que vous saisissez (budgets, transactions, objectifs financiers) sont stockées exclusivement sur votre appareil, dans une base de données locale.

Aucun compte requis

L'application ne nécessite aucune création de compte, aucune adresse email, ni aucune information d'identification.

Permissions utilisées

  • Microphone — utilisé uniquement si vous activez la dictée vocale pour saisir une transaction. Aucun enregistrement n'est conservé ni transmis.
  • Stockage — utilisé pour exporter ou importer vos propres sauvegardes de données, à votre initiative.
  • Biométrie (empreinte digitale) — utilisée uniquement pour déverrouiller l'application localement, si vous activez cette option. Aucune donnée biométrique n'est stockée par l'application elle-même — cette vérification est gérée par le système Android.

Partage de données

Aucune donnée n'est partagée avec des tiers. Les fonctions d'export permettent uniquement à l'utilisateur de sauvegarder ou transférer manuellement ses propres données, à sa seule discrétion.

Sécurité

Un code PIN optionnel et le déverrouillage biométrique permettent de protéger l'accès à l'application. Ces données de sécurité (code PIN chiffré) sont stockées uniquement sur l'appareil.

Modifications de cette politique

Cette politique de confidentialité peut être mise à jour occasionnellement. Toute modification sera reflétée par la mise à jour de la date ci-dessus.
