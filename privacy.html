Introduction

Bienvenue sur agnissanisaac.com, site de Agnissan Isaac Valen, fondateur de Code A-Z, agence digitale basée à Abidjan, Côte d'Ivoire.

Cette politique de confidentialité explique comment nous collectons, utilisons et protégeons vos données personnelles lorsque vous visitez mon site. En naviguant sur ce site, vous acceptez les pratiques décrites ci-dessous.

// 01

Données collectées

Nous pouvons collecter les types de données suivants :

  • Données de navigation : adresse IP, type de navigateur, pages visitées, durée de visite
  • Données de formulaire : nom, email, message — uniquement si vous remplissez le formulaire de contact
  • Données techniques : résolution d'écran, système d'exploitation, source de trafic

Nous ne collectons aucune donnée sensible (informations bancaires, données de santé, etc.).

// 02

Utilisation des données

Les données collectées sont utilisées pour :

  • Améliorer l'expérience de navigation sur le site
  • Répondre aux demandes envoyées via le formulaire de contact
  • Analyser le trafic et les performances du site via Google Analytics
  • Diffuser des annonces publicitaires pertinentes via Google AdSense

Vos données ne sont jamais vendues à des tiers.

// 03

Cookies et technologies similaires

Ce site utilise des cookies — de petits fichiers texte stockés sur votre appareil — pour améliorer votre expérience. Les cookies utilisés sont :

  • Cookies analytiques : Google Analytics, pour mesurer l'audience
  • Cookies publicitaires : Google AdSense, pour afficher des annonces personnalisées
  • Cookies fonctionnels : pour mémoriser vos préférences de navigation
Vous pouvez désactiver les cookies dans les paramètres de votre navigateur à tout moment. Certaines fonctionnalités du site peuvent être affectées.

// 04

Google AdSense et publicités

Ce site utilise Google AdSense pour afficher des annonces publicitaires. Google utilise des cookies pour diffuser des annonces basées sur vos visites antérieures sur ce site et d'autres sites.

Google, en tant que fournisseur tiers, utilise des cookies pour diffuser des annonces. Vous pouvez désactiver la personnalisation des annonces en visitant les Paramètres des annonces Google.

Pour en savoir plus sur l'utilisation des données par Google : Politique de confidentialité Google.

// 05

Google Analytics

Nous utilisons Google Analytics pour analyser le trafic de ce site. Ce service collecte des données anonymisées sur votre comportement de navigation (pages visitées, durée, provenance).

Ces données sont traitées par Google conformément à leur politique de confidentialité. Vous pouvez vous opposer à la collecte de ces données en installant le module de désactivation Google Analytics.

// 06

Partage des données

Nous ne vendons, ne louons et ne partageons pas vos données personnelles avec des tiers, sauf dans les cas suivants :

  • Prestataires techniques nécessaires au fonctionnement du site (Google Analytics, Google AdSense)
  • Obligation légale : si la loi l'exige

// 07

Vos droits

Conformément au Règlement Général sur la Protection des Données (RGPD) et aux lois applicables, vous disposez des droits suivants :

  • Droit d'accès : connaître les données vous concernant
  • Droit de rectification : corriger des données inexactes
  • Droit à l'effacement : demander la suppression de vos données
  • Droit d'opposition : vous opposer au traitement de vos données
  • Droit à la portabilité : recevoir vos données dans un format lisible

Pour exercer ces droits, contactez-nous à : valenbouge@gmail.com

// 08

Sécurité

Nous mettons en œuvre des mesures techniques appropriées pour protéger vos données contre tout accès non autorisé, perte ou divulgation. Ce site est hébergé via GitHub Pages avec HTTPS activé.

Aucun système n'est infaillible. En cas de violation de données, nous prendrons les mesures nécessaires conformément aux obligations légales applicables.

// 09

  • Localisation : Abidjan, Côte d'Ivoire
